# Fokir Portfolio

A responsive single-page portfolio for Alex Smith, presenting an introduction, services, selected work, client feedback, blog cards, and a contact form.

## Features

- Semantic page landmarks and keyboard-accessible navigation
- Responsive layouts for phone, tablet, and desktop screens
- Sticky navigation with active-section indication and a Bootstrap mobile menu
- Client-side portfolio category filters
- Contact form that prepares a message in the visitor's default email application
- Reduced-motion support and visible keyboard focus styles

## Tech Stack

- HTML5 and CSS3
- Vanilla JavaScript (ES6+)
- Bootstrap 5 styles and bundled components, included locally
- Lato typeface from Google Fonts

## Run Locally

No build step or package installation is required. Open `index.html` in a browser, or serve this folder with any static web server. Bootstrap, page styles, scripts, images, and font files are referenced from the project directory.

## Portfolio Preview

The hero uses `slider-02.jpg`; the profile and project previews use the supplied images in the project root. Open `index.html` to view the complete page and try the section navigation and portfolio filters. The contact form opens an email client addressed to `example@gmail.com`; it does not submit to a web backend.
